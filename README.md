# Literature List v2.0 — Учёт прочитанной литературы (Flask + CI/CD)

![CI/CD](https://github.com/pasha-iden/literature-list-2.0/actions/workflows/tests.yml/badge.svg)

[MIT License](https://img.shields.io/badge/license-MIT-blue.svg)

### Персональное веб-приложение для учёта прочитанной литературы.

Сервер загружает данные из Google Таблицы и формирует структурированную HTML-страницу с группировкой по жанрам и авторам.

Это **вторая версия** проекта. Исходная версия (с Telegram-ботом и PostgreSQL) доступна в репозитории: [pasha-iden/literature-list](https://github.com/pasha-iden/literature-list).

**Ключевое отличие от первой версии:** интерфейс управления перенесён с Telegram-бота на Google Таблицы, внедрён полный цикл CI/CD (тесты, линтеры, контейнеризация, автодеплой).

## Быстрый старт (локально).

#### Подготовить локальный репозиторий:
Создать корневую директорию проекта и перейти в нее.  
Установить python *(используется: Python 3.10.x)*  
Создать виртуальное окружение:
python -m venv venv 

#### Скачать проект в локальный репозиторий:
git clone https://github.com/pasha-iden/literature-list-2.0.git

#### Установить зависимости:
pip install -r requirements-dev.txt

#### Настроить источник данных (Google Таблицы):
Приложение получает данные из публичной Google Таблицы в формате TSV.
Создать свою таблицу (шаблон: https://docs.google.com/spreadsheets/d/1j0bZH_qvpZXy47oVW_FPM2kjoXGG3meWAiP4e9k2Elg/edit?usp=sharing).

Опубликовать: Файл → Поделиться → Опубликовать в интернете.

В окне публикации выбрать вкладку "Лист1" и формат "Таблица с разделителями табуляцией (.tsv)".

Скопировать полученную ссылку.
Вставить в файл main.py в качестве значения переменной TSV_URL. 
*Чтобы строка проходила линтеры, добавить комментарий **# noqa: E501***

#### Запустить проект локально:
python main.py  
*Страница будет доступна в браузере: http://localhost:5000/library*

## Запуск на продакшене.

#### Подготовить локальный, удаленный репозитории и сервер:
Выполнить пункты 1, 2 и 4 из раздела "Быстрый старт".
Создать удаленный репозиторий. Связать локальный и удаленный.
Установить Docker на сервер.

#### Настроить конфигурации репозитория:
В удаленном репозитории создать GHCR_PAT-токен, добавить в GitHub Secrets проекта.
Добавить GitHub Secrets: ssh сервера, пользователя и пароль.
*(при использовании на сервере ssh-ключа заменить в tests.yml строки password на key с соответствующими значениями)*

#### Запустить проект:
Выполнить push любого комита в main ветку.  
При каждом новом комите запушеный контейнер будет заменяться на новый.

## Детали проекта.

### Контейнеризация и CI/CD
Dockerfile — минимальный образ на python:3.10-slim, содержит только продакшен-зависимости.

docker-compose — раздельные конфигурации для разработки и продакшена.

GitHub Actions — полный пайплайн:  
pytest + coverage  
линтеры flake8, black  
сборка Docker-образа  
публикация в ghcr.io  
автоматический деплой на сервер (при пуше в main)

### Стек и архитектура
Добавленный стек: Google Sheets TSV-экспорт, Pytest, Flake8, Black
Архитектура: Docker, Docker Compose, GitHub Actions, GitHub Secrets, GitHub Container Registry, Linux
Унаследованный стек: Python, Flask, HTML, CSS, Jinja2

### Статистика
Новый код: ~650 строк (тесты, CI/CD, интеграция с Google Sheets)    
Унаследовано: ~100 строк (веб-сервер и шаблоны)
